# Support

## Getting help

- **Issues with this repository** — open an issue in
  [vergils-nemesis/.github](https://github.com/vergils-nemesis/.github/issues/new/choose)
  using the issue template.
- **About the methodology** — VERGIL and the VERGIL/MIMIR duality are
  documented at the
  [VERGIL docs site](https://vergil-project.github.io/vergil-tooling/).

## What lives here

`vergils-nemesis` is the adversarial-testing counterpart to the
[VERGIL](https://github.com/vergil-project) methodology. This
organization currently holds a single repository — `.github` — which
provides the org profile and community health files. There is no code
and nothing to release here; questions about the VERGIL tooling itself
belong in the [vergil-project](https://github.com/vergil-project)
organization.

## Expectations

vergils-nemesis is a community project maintained by volunteers. There
is no SLA-backed support. Issues are addressed as time permits. We
appreciate your patience.
